# 全图自然地形审核 · 2026-11-28

用户原话：“这摆一堆石头又是什么意思？？？所有地形必须自然并且符合物理逻辑，整个大地图都要审核一遍”。前两轮把建造限制直接变成逐格石块，虽通过覆盖检查，却制造了连续石墙；该验收方式作废。

## 本轮约束

1. 224×96 全地图及镜头可见外围都进入检查，不能只检查村落。
2. 地形高程决定水岸与通行；陡坡以连续裸岩坡面表现，普通河岸为侵蚀土岸，禁止逐格摆石掩盖限制。自然缓坡允许建筑地基承接。
3. 平原水道按低地潮汐水系处理，必须连续连接海湾。没有可靠依据的山体切海平面溪沟删除；不允许海水从高山上的狭长槽穿过。
4. 山脊、山麓、冲积平原、海岸与岛屿连续过渡。只在实际初始建筑占地下支撑整平，禁止按道路或大矩形资源场切平台。
5. 植被按土壤湿度、坡度与林群分布随机成片；不按每格相同偏移摆芦苇。树根和可见草根必须接触真正渲染的地面。小石仅能是少量自然露头，不作为禁建格的代理。
6. 保留已允许的初始建筑和五座木桥，不增加人造物。桥面、桥脚、两岸引接与实际支撑高度分别检查。
7. 矿石露头集中在西侧基岩山脚；油料点只是玩法假定，不能宣称是当地真实矿藏。自然水道精确曲线、古岸线和岛寨位置同样是玩法设计。

## 改动与结果

- 删除 2,975 个逐格石块及原有稀疏石块批次。裸岩成为山坡表面，普通土岸不再被强制染成岩石或摆放石块。
- 删除 5,550 簇规则芦苇及固定沿岸带。当轮为 405 簇草/芦苇和209棵树；用户随后指出林地过稀，当前已按连续地貌增密，见 [林地覆盖修正](vegetation-cover.md)。植被仍使用连续坐标，不把地块中心当成树位。
- 移除把山体切至海平面的溪沟和两条北侧水道的跨山起点。两支低地水道在南部汇合后入海，全部水体是一片连通水域。潮汐低地可用同一近似水位，不再把同一水位用于高山溪流。
- 删除道路压平、矩形资源场和大面积村落/岛寨压平，仅初始建筑真实占地做基础支撑。可见地形相邻半格最大高差由 11.256 降至 1.435。
- 普通缓坡可以建设；水岸整格判定读取占地最低点是否碰水。明显陡坡和湿土保留限制，具体原因显示在预览里。
- 五座木桥两岸引接高差最大约 0.013，桥内土体到板顶最小分离 0.11，去除土地穿板和共面闪烁源。初始建筑支撑最大误差约 0.019。
- 水面颜色按真实床深插值；海湾与低地水道分别处理浪纹强度，去除全图噪声色块和内河白色发光岸线。

地理结构和物理连续性来自游戏高程及工程检查，不是水动力模拟，也不是 1558 年测绘。资源种类与压缩地图尺度仍属于玩法。没有用这些检查证明真实手机性能或完整战局平衡。
