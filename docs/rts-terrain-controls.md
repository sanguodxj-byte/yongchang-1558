# 地形与 RTS 操作修订 · 2026-11-28

> 本页记录初版RTS改动。用户指出两端场景操作不一致后，输入与验收已修订，当前操作以 [两端操作修复](input-repair.md) 为准；右键支持短按下令/拖动平移，触屏采用独立手势和营造确认。

针对“不能建设的部分必须有明显的障碍物”和“操作手感需要高度模仿要塞和帝国时代系列”，本轮修改正式 Godot 工程，H5 与 Dora 使用同一 PCK。旧 Three.js 参考版不作为本轮运行入口。

## 地形与史料

旧版存在 `X>83` 的逻辑禁建线，扫描确认其中 837 格可建设空地没有地物原因；另有坡度/岸地限制及跨整栋占地的高差限制。修订后取消坐标禁建线，后续全图审核撤销了“禁建格生成石块”的错误做法：限制由真实陡坡、土岸、水面占地和湿土决定，岸边植被自然分布。平缓但略有起伏的合法占地由石基承接。

`obstacle` 表示地形拒绝原因，不再生成逐格石块。全图审核读取真正渲染的地形三角形、水面与物件可见根部；检查连通水系、坡度、岸线占地、支撑与不规则植被。旧“每格有障碍模型”指标作废。详见 `landscape-audit.md`。

伐木清出的格子允许营造；建筑占地内的树不会重新生长并穿过建筑，拆除后才可恢复自然生长。

重新读取的官方依据：

- [2023 年温州市文旅局《永昌堡》](https://wl.wenzhou.gov.cn/art/2023/3/24/art_1653027_58903626.html)：城内凿二渠，居民分住两岸。
- [2015 年温州市旅游局《永昌堡》](https://wl.wenzhou.gov.cn/art/2015/7/7/art_1653048_34538409.html)：上河、下河引水入城，贯穿南北；分别向西、向东开五浃。

这能确认堡内水系，不能确认游戏里的间距、宽度、准确古河道或建堡前布局。主渠参数宽度由 1.65 降至 0.95 格，岸坡过渡收窄，村落段按后续要求保留自然河岸，禁止预建石砌护岸。这是改善尺度和用途表达，不是新发现的历史测绘。历史支渠没有逐条复建，虚构岛寨与岸线边界仍按原说明处理。

## 交互

| 输入 | 行为 |
| --- | --- |
| 左键单位 / 拖框 | 选择小队 / 多支小队及宗长；空地单击取消选择 |
| Shift + 左键 / 拖框 | 切换或增加选择 |
| 双击单位 | 选中屏幕内同类小队 |
| 右键地面 / 敌人 | 移动 / 指定攻击，出现落点反馈 |
| Shift + 右键 | 追加路点；前一命令完成后执行下一条 |
| S / A 后左键 | 停止并清空路点 / 攻击移动 |
| Ctrl + 数字 / 数字 / 连按数字 | 保存编队 / 召回 / 定位 |
| H / 空格 | 回宗祠 / 定位选择 |
| 中键拖动 / 边缘 / 方向键 | 平移镜头 |
| 滚轮 / Q、E / M | 指针锚定缩放 / 旋转 / 全图 |
| 小地图左键 / 拖动 / 右键 | 定位 / 拖动视野 / 下令 |
| 营造左键 / R / 右键或 Esc | 放置 / 旋转 / 取消 |

营造显示整栋轮廓、附近占地网格、红叉和具体错误，不只依赖颜色。城墙/油壕显示整条拖线预览，资源不足或障碍后停止；剩余部分标红。快捷操作与 UI 松键、双指手势隔离，防止误放或镜头持续拖动。触摸保留点选后点地调遣与双指镜头手势。

小队仍是当前游戏的选择与指挥单位；没有把经济单位改为帝国时代式逐个农民任务系统，也没有宣称寻路、战斗节奏与商业作品完全一致。
