# 可粘贴的作品信息

## 作品名称

守望1558：永昌风云

## 团队与提交人

格尼尔工作室；队长/提交人：三哒锅酱。

## 一句话简介

从四户村落起步，经营粮械、筑城募勇、乘舟反攻，守望永昌乡土。

## 玩法简介

《守望1558：永昌风云》是一款国风低模海防筑城策略游戏。玩家从四户村落起步，在山麓、林地与田间安排生产，修筑防线，招募乡勇，守护宗祠与宗长，最终集结部队乘舟反攻海岛。

资源需要经过实际劳动与运输：民丁按工种持镰、斧、镐、锯或锤，完成采集、加工与入库。堆放场可以自主建设，选址影响运输；采石场可独立生产，另配绑牛桩后由牛车运石，每批产量从6石增至9石。玩家需要让资源到达需要它的地方，再将粮械转化为城防和部队。

战斗包含两路防守、六类兵种与渡海攻寨。鸟铳手可驻防，冲车与炮车承担攻坚任务。宗族义捐、驰援、驻祠和乡约提供不同的整备选择；生产扩张、人口容量、守城与远征需要相互协调。游戏提供新手准备、资源定位、工坊状态、存档恢复及胜负后的直接重开。

## 与「守·望」赛题的关系

“守”落在玩家当下的行动里：让粮食入库、保持运输通路、修筑两路防线，守住宗祠与乡民的家园。“望”体现在准备下一步的过程中：从四户村落逐步形成可以自给、募勇和远征的共同体，把眼前的生存延伸为对未来的经营。

作品以永昌堡及英桥王氏背景为创作起点，将合族义捐、乡约互助与堡内耕战转化为可操作机制。历史人物与文化背景参考公开资料；海岛敌营、战局节奏、部分建筑组合及数值是玩法设计，不宣称精确复原1558年的地理与战事。

## 主要特点

1. 实体生产运输：工种工具、加工动作、可建堆场及独立绑牛桩组成可观察的资源链。
2. 从守城到渡海：经营、军工、六类兵种、两路防线与双门岛寨构成完整推进过程。
3. 文化参与决策：宗族互助和耕战自给影响资源、恢复与战力，文化背景与玩法共同出现。
4. 一份开源工程：Godot内容在Dora与H5中共用，附素材来源、许可、构建脚本和验证记录。

## 操作与运行

Windows10/11环境使用兼容Dora版本加载根 `init.lua`；源码先用Godot4.7.2导入 `game/project.godot`。鼠标选择营造与募勇卡，点击地面建设/调兵；WASD、右键拖动、滚轮、Q/E控制镜头，M切全图，Esc收起操作或暂停。新玩家可先进入“新手准备”。

当前验证以Windows桌面及触控模拟为主；真实手机、KTR手柄与长时间性能不作为已通过承诺。

## 评分侧重点建议

- **玩法（1点，+10%）**：生产、运输、城防、募勇与海运具有可观察的因果联系，能够完成完整胜负闭环。
- **创意（1点，+10%）**：以永昌地方文化为背景，把宗族互助和耕战自给落实到经营选择与战斗准备。
