# 永昌堡历史地形与游戏地图

## 当前版本：山海地形 v2（2026-11-26）

正式 Dora/H5 地图已升级为共同高程地图。当前唯一布局源为 `content/yongchang-map.json`，模型源为 `content/model-library/`；`scripts/build-terrain.py` 同时生成地形显示、支撑高度、坡度/可建造数据、林群和水面。早期 `src/yongchangMap.js` 是保留的 Three.js 迁移对照，以下旧坐标表说明 v1 背景，v2 以[地图设计规范](terrain-design.md)及 JSON 为准。

v2 将西部直线山墙改为多支山脊与山脚缓坡；原矩形道路改成顺坡、绕田的曲线路径；田块沿渠道展开，保留撂荒耕地，不赠送生产建筑；河渠向地图外延续并联系东南海湾；海岸从平地经湿草泥岸过渡到浅湾，岛寨为非对称岬角与港湾。森林以群落组织，避让桥头、资源工作区与主要行军道。沿用原有村落、桥与码头锚点以及四户开局。

史实复核采用温州市官方页面，并以现代 SRTM 粗分辨率剖面核对西高东低的地形关系。现代高程只作关系校验，不能证明明代海岸或古河道。玩法地图仍有比例压缩、渠道推定与虚构岛寨，不能称为历史测绘复原。

## 依据与取舍

2026-11-25 核对以下公开资料全文：

1. [温州市文化广电旅游局《永昌堡》，2023-03-24](https://wl.wenzhou.gov.cn/art/2023/3/24/art_1653027_58903626.html)：1558 年建堡，长方形，南北 738 米、东西 445 米、周长 2366 米；外有护城河，内凿二渠，居民沿渠而居。
2. [温州市旅游局《永昌堡》，2015-07-07](https://wl.wenzhou.gov.cn/art/2015/7/7/art_1653048_34538409.html)：四座陆门、四座水门；上河、下河南北贯通，各向外分五浃；上河七桥、下河四桥。陆门按东、南、西、北分别为环海、迎川、镇山、通市。
3. [叶克飞《东南海防古堡②：永昌堡》，澎湃号，2020-08-31](https://www.thepaper.cn/newsDetail_forward_8953525)：东门瓮城、13 座敌台、堡内百余亩田地；王氏祖祠早于城堡，建于 1542 年；都堂第、状元第等为更晚建筑。该文为作者走访文章，作为补充资料。

尺寸存在版本差异：2015 年页面同时写 455/445 米，且含明显周长笔误；其他资料有南北 778.3 米的版本。本地图采用 2023 年官方页面的 738×445 米作为形状参照，不声称复原历史测绘。西倚山麓、东向海滨是地理关系；历史岸线距离、准确河道曲线、桥位、每座敌台位置和田亩边界未得到可靠测绘，本作均为示意。

## 核心玩法：从村落建设要塞

用户明确要求：**这是要塞玩法，玩家必须从普通村落开始建设。** 历史资料用于地理关系与可发展的空间，不把已经建成的永昌堡直接送给玩家。

开局仅保留宗祠、社火坛、物资堆、粮仓、武备架和四户旧居。防御建筑（城墙、城门、敌台、火炮台、水门、瓮城）为零，生产建筑（农场、伐木、采石、矿冶、军器作坊）为零；不自动解锁筑城与耕战奖励。四户旧居只表现村庄已有住户，不额外增加人口上限，后续住房和产线由玩家出资营造。

开局没有环形护城河和城镇棋盘街区。场景保留双渠、五座乡桥、土路与可开垦田地，用作水乡村落的交通基础。田地是地形，无成熟稻作装饰冒充可产粮农场；粮食生产必须由玩家建设农场并派乡民工作。双渠借鉴历史永昌堡水系，不声称其建堡前已是同样形态。历史上7+4座内桥与4座水门仅记入资料，不等同于开局设施。

## 验收

- 开局玩家防御建筑0、生产建筑0、旧居4户；原有筑城/耕战奖励均锁定。
- 村落向东、西、南、北均可行军，尚无免费封闭防御圈；斥候应报告未封堵来路。
- 五座乡桥可通步兵与牛车，未架桥的水面继续阻挡。
- 建造农场、伐木坊、城墙和城门会扣费、占地并获得真实工作/防御功能；放置失败不扣费；生产需要招聘工人。
- 资源运送和东/北来袭使用新地图坐标，建造与镜头边界随扩图生效。
- 小地图可点击定位，M切换全图；真实浏览器检查开局、全景、村落、桥梁与海滨。

## 已知历史精度边界

这是依据公开历史资料制作的要塞建设场景，不是建成永昌堡的数字测绘。没有精确复原1558年的道路、原始地貌、海岸距离或每栋宅院位置；后建的都堂第、状元第未放入1558年开局。成熟堡城的围城事件与年代表演仍为游戏叙事，需要与历史实景分别理解。

以下是大陆112×96阶段的原始结果；160×96岛寨及视觉修复的新增验收见[开发接续记录](development-state.md)。
