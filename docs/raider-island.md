# 倭寇岛寨：史料、场景与玩法

## 史料边界

2026-11-25 阅读《明史》卷205的朱纨、胡宗宪相关记载。原文包括：

- “番舶後至者不得入，分泊南麂、礁門、青山、下八諸島。”
- “汪直據五島煽諸倭入寇，而徐海、陳東、麻葉等巢柘林、乍浦、川沙窪。”
- “滶與謝和……柵舟山，阻岑港而守。”

出处：[《明史》卷205，维基文库转录](https://zh.wikisource.org/wiki/明史/卷205)。可见岛屿驻泊、海岛寨栅与大陆营地都存在，不能把“倭寇据点必然全在海岛”当作定论。

[双屿港资料](https://zh.wikipedia.org/wiki/双屿港)用于理解岛间港湾与海商设施，不能把1548年已被毁的双屿港直接放到1558年的永昌堡对面。[世界史の窓《倭寇》](https://www.y-history.net/appendix/wh0801-011.html)引述田中健夫、村井章介等研究，介绍后期海上集团包含多种来源的成员及贸易活动。因此本作采用帆船、货栈、修船棚、木栅与岗楼，避免把敌营统一塑造成成熟日本城郭。

没有查到能把永昌堡的某次围攻直接对应到某座具体近海岛寨的可靠证据。游戏里的“黑鲨岛寨”、虚构首领、船只数量、岛岸距离、码头和登陆路线均为玩法创作；不标注为南麂、舟山或双屿实景。

## 2026-11-26 地形更新

v2 岛屿轮廓改为非对称曲岸，北/东部以岩脊围合港湾，营地与旧码头锚点保留；海岸、步行区和船舶上岸的支撑高度来自同一份高程。岛寨的名称、形状与大陆距离仍属玩法虚构。原有仓棚、码头附件、停泊船、木栅与修船细节保留。

## 游戏闭环

敌方夜袭在岛港生成部队并登上运输船，抵岸后才开始陆上行军。玩家切换“进攻”时，大陆部队全部到渡口集结后，以1秒间隔乘舟赴岛，登岸后继续攻击岛寨；手动拖动至另一岸也使用同样的渡海环节。船只阶段遵守游戏暂停与速度；海峡始终不可步行。村民经济运输仍留在大陆。

渡船是本轮自动行军功能，暂不引入可购买舰队或独立海战。岛寨与倭酋继续使用现有受伤、坍塌和胜负判定。船寨的视觉丰富度不能以封死登陆口或让反攻目标不可达为代价。

## 远海防线与验收

敌岛东移64格，新增内寨、两座内寨铳楼、两处岸防炮与第二队守军。外寨门1800、内寨门2200、本营5000耐久。使用现有模型组合城防，未改成日本城郭。当前测试入口为 `scripts/check-fortress.py` 与 `scripts/check-fortress-runtime.py`；设计、范围和结果见 [远海岛寨](offshore-fortress.md)。

## 早期 Three.js 版视觉修复记录（历史）

布棚使用有下垂曲面、缝边和拉绳的双面布料；木栅采用密排尖桩与巡行木板；瞭望台加入交叉支撑和梯子；本营补木板外墙、廊柱、窗棂与台阶。船体有分段舷板、船舷、艉板、舵与独立帆布材质。修改沿用既有占地和渡口布局，未改变城防血量。

`scripts/island-check.py --simulate` 验证小队/冲车渡海攻门、宗长往返、敌军东岸与北岸登陆、暂停/速度，以及开局无免费城防和生产建筑。

`scripts/assault-check.py` 使用脚本配置的41人军队从村落出发，沿真实移动与战斗函数摧毁本营、击败倭酋并打开胜利界面；兵种血量和伤害不变。`--block-crossing` 刻意关闭渡船，脚本必须非零退出。该场景不覆盖军队招募成本和整场四幕平衡。具体结果与证据见[开发接续记录](development-state.md)。
