# 永昌堡渲染风格与验收

> 本文下方为迁移前 Three.js 渲染记录。正式 Dora/H5 使用 `game/`；2026-11-26 的地形 v2 使用 `terrain.gdshader`、共同高程与原材质模型。对应源为 `content/yongchang-map.json`、`scripts/terrain_field.py`、`scripts/build-terrain.py`，验收见 `terrain-design.md` 与 `platform-validation.md`。不要把以下旧 Composer/ACES 管线当成新运行时已实现的能力。

本轮沿用现有明代建筑、灰瓦木构与折面山体，集中调整光照、接触阴影、水面和地表过渡。光照、后处理与水色的统一入口是 `src/renderStyle.js` 的 `DIORAMA_LOOK`；不要在不同调用处重新写一套昼夜参数。

## 画面目标

| 对象 | 画面应满足的条件 | 实现 |
| --- | --- | --- |
| 日间 | 暖日光、略冷背光，灰瓦和石材不泛白；屋檐、树根、建筑底部有层次 | 主光与环境光分工；复用法线深度缓冲的 8 次采样接触遮蔽 |
| 夜间 | 天空、补光、环境反射和色调同步变暗；道路、单位和屋顶仍可辨认，火光突出 | 同一组昼夜配置，指数平滑过渡；不改变战局时钟 |
| 地面 | 山体、草地保留可辨折面，草路边界保持连贯 | 共享基础颜色，按草地/沙土/岩石分别保留0.12/0.08/0.18的面色变化范围；高度与导航数据不变 |
| 河海 | 恢复原有曲线水纹；海上有平静留白，河岸有浅水和泡沫，不出现满屏重复斜纹 | 双层噪声曲线、同一波场导出法线、屏幕导数过滤、连续岸线距离；亮线不自发光 |
| 后处理 | 一次 ACES 与一次 sRGB 转换；只有高亮光源柔和泛光，无逐帧噪点 | 半浮点 MSAA 主缓冲 → 接触遮蔽/描边 → HDR bloom → 最终色调 |
| 镜头与窗口 | 缩放、旋转和高 DPI 调整后尺寸一致；阴影随镜头平移保持稳定 | 光源空间的阴影纹素对齐；Composer 统一管理物理像素尺寸 |
| HUD | 操作按钮文字不折行；战局提示不遮住左上按钮 | 操作行独立定位，通知位于其下方 |

接触遮蔽使用世界半径，最大暗化为 36%，不新增几何预绘制。普通材质、地形仍使用既有 PBR 管线。水面外圈补齐 `aShore` 属性，河流共享角点使用相同岸线距离。

## 本地复查

项目是零构建静态页面。启动 HTTP 服务，再运行检查脚本：

```powershell
python scripts/serve.py
# 在另一个终端运行；替换为本机浏览器可执行文件与输出目录。
python scripts/visual-check.py --browser 'C:\path\to\msedge.exe' --output 'D:\path\to\captures' --label review --dpr 1.5 --audit
```

脚本依赖 Python 的 `playwright` 包，直接使用指定浏览器，无需下载另一份浏览器。它通过真实标题按钮与开始按钮进入游戏，检查控制台和 WebGL 错误，记录没有截图读回干扰的 90 帧时间，并检查：

- 主画布、Composer、法线深度缓冲在启动及三种窗口尺寸下完全一致，bloom 为半分辨率。
- 键盘暂停、恢复、旋转生效；实际昼夜处理函数触发敌军生成。
- 截图使用的 JS/HTML 内容与工作区文件逐字节一致，报告包含 SHA-256；测试期间被其他任务修改会返回失败。
- 输出实际开局、全景、河道、夜间、紧凑窗口截图及 12 帧移动序列。

全景、河道、夜间截图是注明状态的场景检查：冻结模拟并设置镜头/光照；开局、输入和夜袭流程通过游戏真实路径验证。脚本没有修改存盘数据，也不跳过图形错误。截图需人工打开复查，脚本通过不代表美术质量自动通过。

## 本轮验证边界

Windows / Edge / RTX 4060 Ti 的桌面浏览器已运行；覆盖 DPR 1 与 1.5、昼夜场景和窗口缩放。性能记录是短时采样，不能外推为所有设备或完整战局的性能保证。紧凑尺寸是桌面浏览器模拟，未在真实手机运行；该历史渲染轮次未做整场通关与音频验收；后续远海版已完成一条H5正常经济真实输入通关，详见当前平台验收，音频听审仍未完成。

独立审查代理未能启动，服务返回模型不可用（404）；本轮图像、源代码和运行报告由执行代理复查。截图与 JSON 证据保存在任务的 visualizations 输出目录，不加入游戏发布资源。

## 2026-11-25 用户反馈后的修复

首轮着色器将原有曲线波纹改成了方向性细纹，未保持用户认可的原始观感。本次根据改动前截图恢复曲线水纹，并对开阔海面的线条做稀疏变化；不恢复原先随机自发光闪点。地表补回折面色阶。岛寨新增模型补足木构、布棚、船舷细节，帆布使用独立材质编号，不再套用木纹。

历史时间线、范围和本次验证见[开发接续记录](development-state.md)。参数仍统一来自 `DIORAMA_LOOK`。下一次改变水纹或地表风格前，应保留同机位、同时间和同缩放的对照截图。
