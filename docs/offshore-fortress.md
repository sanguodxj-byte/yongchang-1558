# 远海岛寨与后期反攻 · 2026-11-26

接续要求：“把敌方倭寇营地拉远一些，目前离太近了，然后加强倭寇营地的城防，需要后期才能主动进攻并且胜利”。

数值均为玩法设计，不属于明代实测距离。唯一布局源为 `content/yongchang-map.json`。地图从 160×96 向东扩展至 224×96；大陆村落、资源和渠道保留原网格坐标，敌岛、仓棚、码头、停泊船及岛上地形整体东移 64 格。

城防采用可摧毁的外栅、内寨、四座驻铳哨塔、两处炮台和两队守军。本营耐久从 2200 调整为 5000。

开局资源及义军突袭应被守军挡住；后期通过生产、扩充人口和积累冲车/炮车配合步兵取得胜利。进攻命令保持可用，难度来自可见防御和兵力准备，不设无敌或时间锁。

## 验收要求

- 渲染、碰撞、地表支撑、小地图、全图镜头和双向海运全部采用新布局。
- 外寨完整时不能绕过围墙进入本营；内寨也应形成独立可突破防线。门毁后须有通路，不能以卡路阻止胜利。
- 初始村落、生产运输、敌袭、宗长往返和六兵种招募保持可用。
- 记录开局合法兵力突袭、固定攻城军，以及正常生产/招募全局三类证据；赠送军队的场景不得冒充经济通关。
- Dora 与 H5 从同一工程生成字节相同的 PCK，并对新地图实际载入、操作、截图和内容哈希进行复核。

## 配套行为与回归

- 海运和相机使用地图尺寸及岸线分区，不再依赖旧版世界坐标 `x > 28`。自动进攻等待大陆的出征小队在渡口集结，然后每秒放行一艘；手动跨岸命令及宗长往返仍可独立执行。敌军保持原2.6秒放船节奏。
- 虎蹲炮车在射程内优先压制炮台、铳楼、寨门，之后再清除木栅和本营；同样规则适用于敌我攻城炮。
- 修复已有冲车78%、藤牌兵45%的小型远程伤害抗性未参与结算的问题；炮击与近战不受该抗性减免。
- 界面和公共模拟统一调用营火募兵入口，移除旧界面的(2,2)出生偏移。新增围堵旧出生点的负例和营火新兵可达检查，防止密集城防把部队生在封闭单格中。
- 全图镜头按224格宽度取景，北向朝上；正常村落视角保留原倾角。原建筑、人物、船只模型继续复用，码头和岛屿装饰一同搬迁。

## 当前证据

公共逻辑109项通过；岛寨专项14项通过，包含外/内寨不可绕行、破双门可通、手动冲车往返、炮车目标选择、冲车抗远程、两组开局突袭失败，以及正常生产/招募后胜利。地形11项通过，86,657个渲染顶点与支撑高程最大误差约4.77e-7格。已验证417棵经济树落地、九个资源点可达和两岸水域隔离。

两组开局突袭均使用真实初始资源、两次义捐和一次驰援，未赠送兵力；初始步兵组23人、攻城组19人，均未摧毁本营。另以三炮车、三冲车加驰援和赈乡士气进行极限开局探针，192.1秒因宗长阵亡告负，本营仍为5000耐久。该探针保留在 `.build/offshore-camp/early-probe.gd` 与日志中，作为补充证据。

正常经济模拟通过25次合法建设和19次付费招募，在340秒发起反攻，454.9秒击败倭酋；45名出征单位实际登陆。守军、敌袭、人口、生产运输及资源扣费保持启用。

公共测试的另一场攻城使用直接提供的38人军队及耕战/赈乡加成，仅用于战斗机制回归，不作为经济通关证明。正常经济场景由脚本做出及时、准确的决策，不能外推为新手平均难度或人类试玩评价。

H5导出包随后通过真实输入完成整局：25次建设、19次付费招募，352.67秒反攻、471.03秒胜利，45人登陆，浏览器错误0。Dora原生14项检查及双端12界面×4窗口一致性检查通过；全流程实测没有写入游戏状态或赠送资源/兵力。
