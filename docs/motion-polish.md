# 动作接触与姿态精修 · 2026-11-27

本轮针对“动画违背物理逻辑”重新验收。此前检查只能证明关节在动，未证明脚底落地、肩臂连接、握持和工具接触正确。

## 复现

旧动作以独立正弦角度驱动四肢，躯干前倾时肩膀仍固定在根骨骼上。基线检查测得肩部位置相对躯干偏差0.072格；静止时脚底漂动0.0076格；240帧行走采样中152帧双脚同时高于地面，贴地帧间位移最高0.0226格。原报告与备份位于 `.build/motion-polish/baseline/`、`before/`。

## 实现

- 人物使用15骨骼：头和肩臂从属于躯干，新增独立脚掌骨骼。腿部在原有膝盖边界分段，武器按完整几何部件保留，避免弯肘时刀刃或袖口被拆成分别转动的三角面。
- 步频由实际位移驱动，碰墙或停止移动时不原地踏步。脚底接触阶段锁定世界位置，抬脚使用关键高度曲线；骨盆高度根据腿长和坡面支撑调整，脚掌保持水平。停止后交替收脚，避免同时抬脚。乘船时脚底改为跟随甲板，不锁在世界原点。
- 工作动作集中在 `motion_clips.gd`，使用准备、抬举、发力、接触保持、收回的关键姿势。双手斧/镐的左手跟随同一工具握点；单手锯、勺、镰、锤有独立动作。接触求解只把手脚放回握点/地面，关节不延长。手腕相对前臂的偏转限制约20度。
- 采集和加工分别选工具：伐木采集持斧、加工持锯；采石/采矿采集持镐、加工持锤；农田采集持镰、加工持锤。工作位置显示对应木料、石料、工台或油桶，使工具轨迹有可见目标。
- 搬运物位于双手之间并随握持位置移动；持物时收起工具。工种/工作状态切换使用缓入过渡，暂停保持同一模拟时间。
- 马和牛使用分节腿与蹄部接触，骑手跟随马身。车轮角度由路程除以轮半径得到；炮管后坐、冲车撞木独立运动，不拉动整个车体。

## 检查与证据

`python scripts/check-motion-physics.py` 使用实际Godot骨骼检查肩臂连接、脚底、坡面、停步、握点、腕肘角度、避脸、工作接触、负重、马牛蹄部、车轮与乘船支撑。覆盖0.4、1.5、2.85格/秒和12%坡面。测试度量的是该模型与这些场景，不能外推为所有障碍、地形和所有姿态的物理模拟。

`python scripts/capture-motion.py --mode work` 与 `--mode walk` 各输出96帧、24FPS检视序列、GIF和关键帧矩阵。独立SubViewport与强制绘制避免宿主窗口被遮挡后截取到旧帧。检视采用与游戏相同模型、骨骼和姿态代码。

`scripts/check-worksites-runtime.py` 在H5中实际建设和运行工坊，通过只读观测记录动作、手部误差、脚底与地形高度；状态变更来自真实鼠标/键盘输入。Dora与H5运行结果、最终PCK哈希见 [平台验收](platform-validation.md) 和 `dist/VALIDATION.json`。

这是针对原低模角色制作的关键姿势与接触约束，并非人体动力学或动捕动画。当前没有宣称所有武器战斗帧、所有坡度和接触组合均完成视觉验收；真实手机性能和声音听审仍独立待验收。
