# 永昌海防图志 · 国风 Q 版界面

当前视觉目标来自用户对旧界面“这啥UI风格？中国在哪？”的纠正。中国题材必须体现在字体、版式、器物图标及材质结构中。旧版亮色圆钮、浮雕高光、粗描边白字和圆形资源徽章已替换，`0b2d7e1` 不再作为当前UI风格基准。

## 视觉语言

- **字体**：标题、题签和按钮采用霞鹜文楷 Medium；数值、价格和长说明采用 Sarasa Gothic。无粗白描边，中文字体均使用公开 OFL 授权。
- **色彩与层次**：浅绢纸、墨绿正文、朱砂主操作、青绿选中态、低对比金线。正文字与底色、暗色按钮与浅色字分开配置。
- **造型**：书页和木刻题签式矩形，少量窗棂折角；保持平整，去除充气感和镜面渐变。细条血量分别用玉绿和朱红，并保留双方名称。
- **图标**：统一线宽的原创 SVG；采用木料、条石、稻穗、方孔钱、乡民、营造工具和军旗。名称与图标同时出现，意义不只靠颜色区分。
- **卡牌**：保留实际游戏模型画像；使用短名称、清晰价格与册页外框。完整名称保留在提示文字及操作标识中。
- **标题**：竖排“永昌风云”、戊午朱印叠加于青绿国画封面。图生图以代码版为构图参考，重新绘制山石皴法、淡墨远山、松树和工笔建筑，细化窗棂、城门与船帆。左侧纸色留白承托标题，右上题字移到山峰上方。标题和按钮实时绘制；画面不作为1558年建筑实景复原。

唯一视觉配置为 `content/ui-theme.json`。`scripts/build-ui-skins.py` 输出 `game/assets/ui/theme.json`、皮肤、图标及原始矢量参考，生成 `style-provenance.json`。当前封面 `title-guohua.png` 为两阶段图生图国画重绘，完整来源、提示词与参数见 `content/cover-generation.json`；不使用外部参考素材。原 `title-atlas.svg` 继续保留，皮肤生成器不会覆盖国画PNG。

## 交互与布局

Dora/H5 共用 `game/scripts/mobile_ui.gd`，固定1600×1000画布等比显示。常驻入口仍为宗族、速度、暂停、全图、营造、募勇、军令，共7个；宗族/军令按需展开，义捐/驰援耗尽后隐藏，修城/引火按条件出现。

常驻面板沿屏幕边缘布置；转向和取消移到下沿，中央地面用于营造与调兵。弹出面板可用原入口、Esc或空白点击关闭，关闭点击不能穿透下令。

所有按钮使用相同悬停、按下及键盘焦点规则。卡牌名称缩短只影响显示，建造、募兵的类型和数值不变。

## 文字与边框间距

角饰限制在面板外侧18像素区域，面板内容左右留24像素、上下留22像素。普通按钮、标签页和卡牌改用无角饰的边线，保留册页轮廓；按钮内容留22×12像素，窄按钮14×12像素，卡牌16×14像素。

按钮内部容器和皮肤使用同一组边距，选中状态只换颜色与贴图，不改变内容区。卡牌独立分配画像、名称与价格高度；三项资源价格分两行，避免炮车/冲车价格横向碰边；资源栏、宗族/军令面板和标题朱印扩大到可容纳安全内容区的尺寸。所有值集中在 `content/ui-theme.json` 的 `layout` 中。

本次针对用户指出的“字体和边框装饰重合”修正；上轮仅核对了文字裁切，未识别角饰侵入文字的问题。本轮另做了原尺寸局部前后对照，证据写入 `.build/ui-spacing/`。
