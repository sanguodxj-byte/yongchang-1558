# 永昌山海地图设计规范 · 2026-11-26

本轮目标是具有可信自然地形结构的 RTS 地图。地图取材于永昌堡和永强滨海水乡，保留四户村落、零免费生产/防御设施、玩家筑城与海运反攻。已确认、推定、玩法虚构分别列出；不声称复原 1558 年测绘。

## 史实依据

- 温州市文化广电旅游局 2023-03-24《永昌堡》：1558 年、南北 738 米、东西 445 米、外护城河、内二渠、沿渠居住。[原文](https://wl.wenzhou.gov.cn/art/2023/3/24/art_1653027_58903626.html)
- 市旅游局 2015-07-07《永昌堡》：上河、下河贯通南北，东西南北陆门为环海/镇山/迎川/通市，四座水门，上河七桥下河四桥。页面内部 455/445 米及周长有笔误，不把所有数字照单采用。[原文](https://wl.wenzhou.gov.cn/art/2015/7/7/art_1653048_34538409.html)
- 现代地形核对：以现址纬度约 27.90559°N 作东西剖面，OpenTopoData 的 SRTM90m 查询在 120.75/120.77/120.79°E 返回约 566/294/291 米，在 120.80/120.80967/120.83°E 返回约 6/10/6 米。支持西部山地—山脚突降—东部低平地的结构；该现代粗分辨率数据不能证明明代岸线、古河床或古田界。[查询](https://api.opentopodata.org/v1/srtm90m?locations=27.90559,120.75%7C27.90559,120.77%7C27.90559,120.79%7C27.90559,120.8%7C27.90559,120.80967%7C27.90559,120.83)

## 地形与 RTS 绘制方法

参考《帝国时代 IV》官方内容编辑器的方法：先用语义地块确定结构，再雕刻高程、修平建设区和通路，最后用渐变地表、样条道路与局部物件细化。参考的是方法，不导入游戏地图或素材。

- [Terrain Layout Tool](https://support.ageofempires.com/hc/en-us/articles/4544564998420-Using-the-Terrain-Layout-Tool)：地形类型网格作为地图结构蓝图。
- [Sculpting Terrain](https://support.ageofempires.com/hc/en-us/articles/5264798022548-Sculpting-Terrain)：山谷、台地、羽化、平整与平滑。
- [Deforming Terrain Along Splines](https://support.ageofempires.com/hc/en-us/articles/4418066345748-Deforming-Terrain-Along-Splines)：沿线路组织地形。
- [Placing Splats and Decals](https://support.ageofempires.com/hc/en-us/articles/4417275201044-Placing-Splats-and-Decals)：用局部材质层建立过渡和使用痕迹。

远海调整将敌岛整体东移64格，保留大陆网格锚点；对应路线、防御设计和当前验收见 [远海岛寨](offshore-fortress.md)。

## 唯一坐标源

`content/yongchang-map.json` 定义山脊、渠道、道路、田块、林群、桥梁及路线目标。生成器同时输出地表网格、单位支撑高度、坡度、可建造范围和导航数据，两端读取同一份结果。

游戏为 224×96 格，北=-Z、东=+X。建设参照宽 36、长 60 格；两条独立历史尺度给出 445/36≈12.36 与 738/60≈12.30 米/格，仅用于验证镇区形状比例相符，不把人物大小或压缩后的山海距离宣称为真实米数。

## 可操作性与验收

- 主路宽约2.2..2.6格，乡道约1.25..2格；既有五桥两格宽，码头登陆区域保持开放。
- 建造前同时核对水面、桥、坡度及整个占地高差；无效放置不扣费。坡地拾取使用真实高程，不再与固定Y平面求交。
- 乡民、步兵、骑兵/冲车的路线、贴地、桥面与上岸分别检查；推挤不能把单位推上陡坡或水面。
- 主村至东港路径50..95格，至北港65..135格；采石至仓20..65格，矿区至仓30..80格；岛港至营地10..55格。均为玩法目标。
- 建造/运输/海运/攻寨既有测试继续通过；新增坡度、地表命中、资源可达与无免费防御圈检查。
- 画面证据至少包括全图、村落双渠、西部山麓、滨海与岛寨。两端记录同内容哈希，并使用当前国风 Q 版 UI（见 `ui-style.md`）。
