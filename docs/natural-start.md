# 自然开局与木桥 · 2026-11-28

用户要求：“禁止有初始建筑以外的人造物，桥梁做成木头的”。这条约束覆盖开局地形布景，并替代前一版石砌渠岸方案。

- 保留原初始建筑，包含村落宗祠、社火坛、四户旧居、物资堆、粮仓和武备架，以及已有敌方岛寨建筑。五座乡桥为明确允许的例外。
- 五座桥重新生成木板桥面、纵梁、木桩、双层木栏与斜撑，全部使用木材表面；桥面高度仍为 0.4，通道净宽 1.76，供步兵、牛车与攻城单位通过。
- 删除石砌护岸、预置木栈桥码头、四艘装饰停泊船、独立灯杆、旗杆、渔网和码头装饰；已属于初始建筑模型的细部保留。
- 删除铺设道路色带、车辙、预耕条垄和田埂。逻辑上的通行走廊/未来农田留白仍用于保持路线畅通，画面为自然草地。
- 油料点显示为不规则天然渗油/泥炭洼地，无容器或人工围边。
- 全图审核后，建设限制来自真实陡坡、水岸占地和湿土。已彻底删除逐格石块与固定密度芦苇；裸岩直接属于连续地形，岸边草木按湿度随机成片。没有隐形码头通行面。

主渡滩改为大陆格点 `(94,49)`，北渡滩为 `(98,22)`，岛岸仍为 `(181,49)`；这些位置读取真实陆地高程，不再由码头桥面托住。实际海运期间的船只仍由运输系统生成，航程端点和海上航行时长不变。

`content/yongchang-map.json` 是布局来源；`scripts/build-terrain.py` 生成场景，`scripts/natural_scenery.py` 生成木桥和自然油料点。生成物依赖哈希包含新增脚本。

验证：`scripts/check-initial-scenery.py` 检查场景根节点白名单、五座木桥的真实材质/桥面/法线、仅40格实际桥面、无铺路/耕地/石岸标记，以及三个渡滩真实可行走；`scripts/check-terrain.py` 检查真实地形限制和可达性，`scripts/audit-landscape.py` 审核整个地图的水系、地面与物件支撑；共同玩法测试检查木桥双向通行、生产运输与海运。

此版地图内容哈希改变，试玩需新开一局。历史上的堡内二渠、支渠记载仍保留为背景资料；自然开局画面属于玩家筑城前的玩法示意，不是历史测绘复原。
