# Dora / H5 同源约束

用户要求两个平台同步制作，内容完全一致。

正式游戏只维护 `game/` 下的一份 Godot 4.7 工程，包含玩法、地图、模型、UI、声音、文本及参数。Dora 使用 `GodotNode`，H5 使用同工程的 Godot Web 运行时。发布流程将同一个内容包交给两个平台，并核对 SHA-256；不维护 Three.js H5 与 GDScript Dora 两份玩法。

根目录现有 `src/` / `index.html` 是迁移对照源。迁移期间保留用于检查，不将其打包成正式 H5 交付。任何未迁移功能必须列入差异清单，不得把局部可运行标记为内容完全一致。

运行验证至少覆盖：村落开局、建造及旋转/拆除、全部生产链和运输、六类兵种、驻防与调度、海运与四幕来袭、宗族政策/义捐/传承、胜负、暂停/恢复/重开、相机与小地图、声音、触屏。两端执行相同输入与状态断言，并记录所加载的内容包哈希。

界面一致性另行验收，不能从PCK相同直接推导。桌面两端使用1600×1000逻辑画布并居中等比显示；宽度小于1000或高度小于600时均采用共用紧凑布局和窗口尺寸视口。Dora与H5在相同尺寸、同一布局模式下核对标题、菜单、HUD、宗族、军令、营造、募勇、暂停、说明和授权的文字、按钮矩形及输入。跨越布局断点可以重排界面，但须保留游戏状态，不能混用两种布局的截图宣称逐像素一致。

风格按当前“永昌海防图志”设计验收：霞鹜文楷题签、浅绢纸册页、墨绿正文、朱砂主操作、青绿选中态及统一木刻线描图标。保留Q版模型画像，旧版立体圆钮与粗白描边不再是风格基准。两端必须使用同一份字体、皮肤、图标与布局，详见 `docs/ui-style.md`。
