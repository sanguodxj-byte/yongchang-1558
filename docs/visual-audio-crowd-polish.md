# 画面、动作、声音与单位避让精修 · 2026-11-28

对应反馈：“画面还是缺乏质感”“骨骼动画也不太行”“音效需要优化，音乐用本地 build music 做几首”“处理碰撞导致抽搐和单位之间穿模”。

## 实现

- 石墙以独立砌块、灰缝与粗糙度区分表面；木材增加顺纹，屋瓦增加瓦垄，布料与金属采用不同高光。纹理固定于物体空间，微表面起伏按像素导数过滤。调整日夜主光与环境光，水面反射和波纹更克制。
- 地面接触阴影使用一个 MultiMesh 绘制，跟随地形坡度与渲染插值；守城、乘船单位不投射错误的地面贴影。
- 接地位置、尺寸和透明度不变时复用阴影变换，避免建筑与停止单位每帧重新读取5次地形并上传相同实例数据；容量增长时清空缓存以重建实例。
- 保留15骨骼、脚底接触与工具握点约束；步态由导航实际行程驱动，碰撞推挤不累计步行里程。增加身体重心转移、头部补偿和较克制的摆臂。30Hz模拟在渲染时插值，转向缓入；船只与乘员采用同一插值时刻。
- 单位按双方体型半径分离，步兵、骑兵、牛车和攻城车采用不同距离。空间桶查询、前方绕行和有限次纠正共同处理拥挤；静止队伍可让位，不反复回到被占用锚点；路径缺乏进展时重算。
- 重算路径后跳过当前起点，避免被挤离格心的大车反复回头、堵住队列。以25次合法建设与19次付费招募的正常经济路线验证：340秒反攻，458.3秒胜利，45名出征单位完成登陆；这是脚本决策下的普通经济模拟，不是注入资源或部队的性能夹具。
- 空闲民丁也参与碰撞和让位，增长人口不重排全部模型。城楼守军站位间隔大于步兵体宽，已有驻位不能重复分配；离开建筑时使用可通行落点。运输集结范围随部队数量增长。
- 音效使用12个可复用播放声部，每种事件预生成3个变体；炮击、箭矢、木石冲击和提示音采用独立包络、音量及触发间隔，空间事件按距离衰减。音乐使用两个播放器切换，暂停降低音乐音量，“声音”开关同时控制配乐与效果音。

## 验证入口与范围

`python scripts/check-polish.py --full` 连续检查拥挤、声音、共同玩法、岛寨与正常经济通关、工种、动作接触、RTS操作和存档。报告包含输入哈希，运行期间源文件变化则判定无效。拥挤检查包括对向交会、到点停止、重合出生、推挤与步频分离、大车间距、空闲民丁增长及部队穿过村民。

原生性能使用 `scripts/benchmark-performance.py`，H5使用 `scripts/benchmark-web-performance.py`。性能计时与截图分开，报告实际画质、帧间隔尾部、脚本开销与竞争进程；本轮场景内容和避让行为已改变，不把历史A/B数值当作当前版本的性能结论。

`.build/polish-v2/motion-visual/` 的96帧工作与行走序列来自相同骨骼代码，属于专用检视场景；材质前后图仅比较相同机位下的着色器及接触阴影。实际游戏验证另行通过导出包、真实鼠标键盘和只读观测完成，报告记录所加载的PCK哈希。

当前保留低模风格与程序编排动作，不称动捕或完整人体动力学。有限拥挤场景不能证明所有地形、武器伸出范围、船内组合和极端兵力都不会穿插；手机硬件性能与人工听审也不由桌面测试代替。

## 本轮性能实测

RTX 4060 Ti、Windows、Godot 4.7.2 / Edge 158硬件WebGL。原生固定60Hz模拟夹具，每场480帧预热、600帧计时；H5从菜单真实点击进入，逻辑画布1600×1000、DPR 1、4×MSAA，每场约10秒。计时期间不截图、不录制。数值是引擎绘制回调间隔，不是GPU计时或物理屏幕呈现延迟。

| 场景 | 原生P95 / P99（毫秒） | H5 P95 / P99（毫秒） |
| --- | --- | --- |
| 村落 | 5.13 / 6.17 | 19.50 / 21.31 |
| 生产 | 6.61 / 7.61 | 20.04 / 21.93 |
| 驻军 | 14.62 / 16.46 | 21.12 / 22.82 |
| 密集交战 | 35.11 / 47.58 | 此轮未测该压力夹具 |
| 全景 | 16.65 / 19.48 | 21.70 / 23.66 |
| 暂停 | 7.21 / 8.18 | 18.93 / 20.15 |

原生两轮分别发生一次焦点丢失自动暂停：`performance-cached`的交战段、`performance-final`的驻军段已明确排除。上表合并同一运行源码的其余有效段，每类仍有600或1200帧，不能表述为“单次六场景全部通过”或严谨交错A/B性能提升。完整有效帧、排除理由与哈希见 `.build/polish-v2/performance-accepted.json`；中断跑次和原始数据也保留。

H5五场景均实际推进或按预期暂停，P50约16.5–16.7毫秒；最慢1%回调换算为24.8–46.0次/秒，存在尾部尖峰。整组浏览器进程RSS峰值约1.34–1.46GiB，包含GPU/浏览器进程，不是单页独占内存。报告位于 `.build/polish-v2/web-performance/report.json`。不能承诺所有场景稳定60FPS，密集交战和真实低配设备仍是后续性能重点。
