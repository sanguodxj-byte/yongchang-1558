# 跨渠水门与完整城防

2026-11-28：修复双渠穿过城墙时无法闭合、可行走河岸却无法筑墙的建设缺口。开局仍只有村落与五座乡桥，所有新增城防由玩家付费修筑。

## 建造

- 营造 → 永昌城防 → **跨渠水门**。点击内渠水面，默认横向跨渠，`R` 转向；预览自动包含两侧干地与岸坡。最多跨7格，两岸必须在4格内，拒绝深水、过宽水面、木桥、树木、矿点和已有非城墙建筑。
- 每座花费石16、木4、铁2，基础耐久900，参与筑堡加成与修城。可替换占地内的己方城墙；放置失败不扣费。拆除返还石8、木2。
- 普通城墙允许在适合的浅岸建设可见石基；其他房屋与工坊仍须干地。城门可守在木桥两端的可行走岸地，保留两格通道。木桥上不叠放城墙或水门。
- 水门由两岸墩台、石拱、铁栅、顶面与垛口组成，使用现有城墙材质。拱下保留原水面，不填平河床。它封住整段岸边通道，地面单位不能把它当作桥通行。

## 防守与存档

敌军会把水门视为可攻击城防，并可从岸上攻破。完整城防没有可绕行的岸边缝；摧毁或拆除水门后，恢复原岸边通路，原水格始终不可步行。友军与工人经陆门、既有乡桥通行。

建筑状态与实际占地沿用现有存档。新增建筑定义位于共用 Godot 玩法层，不重写地形资源，因此保留本次修改前的地图标识和存档兼容条件；不改变原有“不同地图版本不能互读”的校验。

## 验证方法

`python scripts/check-water-defenses.py` 在实际 Godot 会话中检查扣费、失败原子性、浅岸石基、四向放置、修复、拆除、保存恢复、完整双渠围城、敌军攻门、岸边突破、工人/步兵/冲车过桥头城门。围城位于 X28..64、Z18..77，四个水门覆盖北、南渠口；验收夹具提供建材并清理树木，不代表真实经济通关。

`python scripts/capture-water-defenses.py --portrait` 从同一模型生成建造卡画像；`python scripts/capture-water-defenses.py` 拍摄围城、水门正反面、南岸接缝、桥头、预览及桌面/紧凑界面。图像和当前源码哈希位于 `.build/water-defenses/`；模型画像来源与哈希另记于 `content/water-defenses-assets.json`。

水门形制与数值为本作玩法设计。史料中的四座水门只提供“城墙允许水系穿过”的参考，未宣称复原历史结构或位置。
