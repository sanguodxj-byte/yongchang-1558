## 检查方法

1. `python scripts/test-common.py`：村落开局、地图与海峡隔离、建造扣费和无效放置、七条生产链实际运输、六兵种招募、旋转城门占地、友方通行、修复/拆除、驻防/离开、义捐及援军上限、三种政策、四幕配置、火壕伤害、胜负与新局。
2. `scripts/check-h5.py`：从导出目录实际加载 index.html、JS、WASM、PCK，并核对响应字节与收据；真实鼠标/键盘开始、暂停/继续、建田、募勇、义捐、进攻、全图、窗口缩放、音效开关、源码归档、重开。触控模拟覆盖点按、双指平移/缩放、手势不误建、手势后的再次点按。
3. `scripts/check-dora.py`：Dora CLI 载入 init.lua，等待 GodotNode.running 且 lastError 为空，通过 sendPointer/sendKey 发送输入，再使用只读运行时查询检查开始、暂停/恢复、建造扣费、募勇、义捐、进攻和全图；保存原生画面。
4. `scripts/check-ui-parity.py`：真实输入进入两端相同的 12 个界面；读取按钮布局与逻辑画布，核对浏览器画布的居中/等比尺寸，保存对应截图。Godot 暴露的 `audit_ui_hash` 仅用于只读观察，不改游戏状态。UI 一致性不能仅凭内容包哈希宣布通过。

5. `scripts/check-terrain.py` 独立比较地表网格、支撑高程、建筑规则和连通分量；`scripts/check-terrain-runtime.py` 在两端使用相同小地图坐标和真实相机输入。

### 恢复 Q 版手游 UI

以下为按钮精简前的风格恢复背景；当前精简规则及色板见 `docs/ui-style.md`。

风格基准为历史提交 `0b2d7e1:index.html` 的 Glossy Bevelled Game Button Surface：金色、亮蓝、红、绿渐变，深色外轮廓、顶部高光和下缘厚度，白色粗描边文字。保留历史模型，将既有 iconStudio 生成的 14 张建筑/6 张兵种画像及项目原有 SVG 图标导出到共同资产目录，不重新生成另一套模型。

统一 UI 位于 `game/scripts/mobile_ui.gd`：独立标题与主菜单、圆形资源徽章、双血条、带图标的操作按钮、营造/募勇大按钮、三个建造分类及浅色立体卡牌。标题恢复蓝色暮空与灯笼意象。恢复的是原有美术语言，并非旧 DOM 的逐像素复刻；两个新平台仍共享同一套界面与输入路径。卡牌不足资源时变暗，保留文字价格；帮助、授权和暂停沿用同一套色彩与控件。

生成说明与授权来源见 `docs/ui-style.md`。正文、资源数值、当前兵力/计时会随运行时间变化；界面结构比较在相同状态进行。

### 本轮修复的界面差异

用户根据前次截图指出两端不一致，复现后确认在相同 1280×720 窗口中，旧 H5 因 `expand` 把逻辑画布扩至 1777×1000，而 Dora 固定为 1600×1000 并留边，造成按钮位置、边距和地图取景不同。前次拼图还混用了不同尺寸的截图，未构成合格的界面对比。现已统一为固定 1600×1000 渲染画布、居中等比显示及相同留边颜色，并按原输入流程回归，包含缩放后建造与触屏手势。

画面证明采用相同尺寸和相同菜单状态。两次捕获并非同一游戏时间，水纹/人物动画、资源计时可能不同；图像整体像素完全相同不作为结论。原生纹理采样与浏览器缩放也可能有微小抗锯齿差异。按钮内容、位置、尺寸和对应操作需一致。

实测宿主为官方 Dora OpenGL 便携版 1.10.2.12，内嵌 Godot 4.7.2。本机原有 D3D12 版曾因宿主与 Godot 桥后端不匹配而无法启动，不能据此声称所有 Dora 分发版都兼容。Dora Studio 的 Godot 编辑功能不属于本次支持范围。

Godot 无头进程在此机器报告 `Failed to read the root certificate store`。该环境证书错误与脚本加载/玩法测试分别记录，不能表述为引擎日志绝对零错误。
